#Instrucciones del programa:
Para ejecutar el programa se pediran datos de manera ordenada, empezando con el numero de cursos a agregar (EJEMPLO: 3)
y numero de salas a agregar (EJEMPLO: 2 ). Luego por cada curso y sala ingresado debera ingresar el ID del curso (EJEMPLO: INF101), el numero de estudiantes(EJEMPLO:30), la hora de inicio en bloques(EJEMPLO: 8), la hora de termino tambien en bloques(EJEMPLO:10),
la cantidad de requisitos(EJEMPLO: 1) y su requisito correspondiente (EJEMPLO: PROYECTOR). 

NOTA IMPORTANTE: Los bloques deben ser asignados de manera ascendente, si se intenta asignar un bloque menor al ultimo asignado,  el programa
no lo asignara (Ejemplo: Ingresar 5-7 y luego 2-4 esta incorrecto.)

En la salida del programa se mostrara un entero que corresponde a las salas y cursos que quedaron emparejados, seguido de cuales son. Seguido de un entero que corresponde a la cantidad de cursos que quedaron sin sala.
